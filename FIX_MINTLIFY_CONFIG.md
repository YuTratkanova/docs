# Проблема: Mintlify показывает шаблон вместо вашей документации

## Причина
Mintlify подключен к репозиторию `yutratkanova/docs`, но либо:
1. Неправильно указан путь к документации
2. Используется старый конфиг `docs.json` вместо `mint.json`

## Решение

### Шаг 1: Проверьте настройки в Mintlify

1. В Mintlify Dashboard нажмите **"Settings"** в левом меню
2. Перейдите в **"Git settings"**
3. Найдите переключатель **"Set up as monorepo"**
4. **Включите его** (переключите в положение ON)
5. После включения должно появиться поле **"Repository Path"** или **"Docs Path"**
6. В это поле введите: `.` (точка) или оставьте пустым, если документация в корне

### Шаг 2: Проверьте файл конфигурации

В вашем репозитории `C:\Users\Йуля\docs\` должен быть файл `mint.json` (а не `docs.json`).

Если там есть `docs.json` - удалите его, оставьте только `mint.json`.

### Шаг 3: Убедитесь что `mint.json` правильный

Откройте файл `C:\Users\Йуля\docs\mint.json` и проверьте, что там настройки для PandaPay (должно быть `"name": "PandaPay Trade Platform"`).

### Шаг 4: Перезапустите деплой

После изменения настроек:
1. Нажмите кнопку **"Refresh"** (обновление) рядом с "Visit site"
2. Или подождите автоматического обновления (1-2 минуты)

---

## Быстрая проверка

Откройте файл `C:\Users\Йуля\docs\mint.json` и проверьте первую строку:
- Должно быть: `"name": "PandaPay Trade Platform"`
- Не должно быть: `"name": "Mint Starter Kit"`
