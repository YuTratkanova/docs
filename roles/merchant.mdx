# Мерчант (Merchant)

## Кто это?

**Мерчант** - это владельцы бизнеса или сервисов, которые принимают платежи через платформу PandaPay.

Мерчанты создают заявки на обмен, которые затем выполняются трейдерами.

## Доступ

### Личный кабинет мерчанта
- Дашборд с статистикой
- Управление заявками
- История баланса
- Выплаты
- Настройки

### API для создания заявок
- `POST /order` - создание заявки
- `GET /order/{id}` - получение информации о заявке
- `GET /balance` - получение баланса

Подробнее: [Merchant API](/platform/api-merchant/orders)

## Создание заявки

### Через API

```bash
POST /order
Content-Type: application/json
Authorization: Bearer {token}

{
  "amount": 1000,
  "currency": "USD",
  "callback_url": "https://your-site.com/callback"
}
```

### Через админ-панель

1. Войдите в админ-панель
2. Перейдите в раздел "Заявки"
3. Нажмите "Создать заявку"
4. Заполните необходимые поля

## Статусы заявки

- `pending` - ожидает трейдера
- `accepted` - принята трейдером
- `completed` - завершена
- `cancelled` - отменена
- `disputed` - спор

## Уведомления

Система отправляет уведомления о изменении статуса заявки:

- **Callback** - webhook на указанный URL
- **Email** - уведомление на email мерчанта

### Настройка Callback

```json
{
  "callback_url": "https://your-site.com/callback",
  "callback_secret": "your-secret-key"
}
```

Подробнее: [Callbacks](/platform/api-merchant/callbacks)

## Управление балансом

### Просмотр баланса

```bash
GET /balance
Authorization: Bearer {token}
```

### История операций

```bash
GET /balance/history
Authorization: Bearer {token}
```

## Выплаты

Мерчанты могут просматривать информацию о выплатах трейдерам через:
- API эндпоинт `/payouts`
- Интерфейс админ-панели
