# Трейдер (Trader)

## Кто это?

**Трейдер** - это исполнители, которые выполняют заявки мерчантов. Трейдеры принимают заявки, выполняют операции и получают награды за выполнение.

## Доступ

### Личный кабинет трейдера
- Дашборд с доступными заявками
- Управление реквизитами
- История операций
- Выплаты
- Управление устройствами
- Настройки

### Telegram бот
- Уведомления о новых заявках
- Уведомления о статусе заявок
- Быстрый доступ к заявкам

**Telegram боты:**
- Production: [@pandapay24_bot](https://t.me/pandapay24_bot)
- Development: [@pandapay_alerts_bot](https://t.me/pandapay_alerts_bot)

### API для работы с заявками
- `GET /trader/orders` - список доступных заявок
- `POST /trader/orders/{id}/accept` - принятие заявки
- `POST /trader/orders/{id}/complete` - завершение заявки

Подробнее: [Trader API](/platform/api-trader/orders)

## Работа с заявками

### Просмотр доступных заявок

1. Войдите в личный кабинет трейдера
2. Перейдите в раздел "Заявки"
3. Просмотрите список доступных заявок
4. Используйте фильтры для поиска нужных заявок

### Принятие заявки

1. Выберите заявку из списка
2. Проверьте детали заявки
3. Нажмите "Принять заявку"
4. Заявка перейдет в статус `accepted`

### Выполнение заявки

1. После принятия заявки выполните операцию
2. Загрузите скриншот подтверждения (если требуется)
3. Заявка будет автоматически завершена системой или перейдет в статус `completed`

## Управление реквизитами

### Добавление реквизита

1. Перейдите в раздел "Реквизиты"
2. Нажмите "Добавить реквизит"
3. Заполните необходимые поля:
   - Банк
   - Номер счета
   - Валюта
   - Страна
4. Сохраните реквизит

### Требования к реквизитам

- Реквизит должен быть валидным
- Реквизит должен соответствовать валюте заявки
- Реквизит должен быть активным

Подробнее: [Управление реквизитами](/features/requisites)

## Уведомления

Трейдеры получают уведомления через:

- **Telegram бот** - мгновенные уведомления о новых заявках
- **Email** - уведомления о важных событиях
- **В интерфейсе** - уведомления в личном кабинете

### Настройка Telegram бота

1. Перейдите в настройки
2. Введите ваш Telegram User ID
3. Подключите бота к аккаунту
4. Получайте уведомления в Telegram

## Выплаты

После выполнения заявки трейдер получает:

- **Награда** - процент от суммы заявки
- **Комиссия** - может быть вычтена в зависимости от настроек

Выплаты можно просмотреть в разделе "Выплаты" или через API.

Подробнее: [Выплаты](/platform/api-trader/payouts)

## Управление устройствами

Трейдеры могут привязывать устройства для получения уведомлений:

1. Перейдите в раздел "Устройства"
2. Нажмите "Добавить устройство"
3. Введите название устройства
4. Устройство будет привязано к вашему аккаунту
