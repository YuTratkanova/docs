# Тимлид (Team Lead)

## Кто это?

**Тимлид** - это руководители трейдеров, которые координируют работу команды. Тимлиды управляют трейдерами в своей команде, отслеживают статистику и контролируют выполнение заявок.

## Доступ

### Панель тимлида
- Дашборд с статистикой команды
- Управление трейдерами
- Просмотр наград
- Настройки процентов
- История баланса

### Статистика и аналитика
- Общая статистика по команде
- Статистика по каждому трейдеру
- Статистика по заявкам
- История операций

## Управление командой

### Просмотр трейдеров

1. Войдите в панель тимлида
2. Перейдите в раздел "Трейдеры"
3. Просмотрите список трейдеров в вашей команде
4. Используйте фильтры для поиска

### Назначение процентов

Тимлиды могут настраивать проценты для трейдеров:

1. Выберите трейдера из списка
2. Нажмите "Настроить проценты"
3. Установите процент для трейдера
4. Сохраните изменения

### Статистика по трейдерам

Для каждого трейдера доступна статистика:
- Количество выполненных заявок
- Общая сумма операций
- Награды
- Процент выполнения

## Статистика команды

### Общая статистика

- Общее количество заявок команды
- Общая сумма операций
- Средний процент выполнения
- Количество активных трейдеров

### Детальная статистика

- Статистика по периодам
- Статистика по валютам
- Статистика по статусам заявок
- Графики и диаграммы

## Награды

Тимлиды получают награды за работу команды:

- Процент от операций трейдеров
- Бонусы за достижение целей
- Дополнительные награды

Просмотреть награды можно в разделе "Награды".

## Контроль выполнения заявок

Тимлиды могут отслеживать:

- Активные заявки команды
- Завершенные заявки
- Заявки в споре
- История операций
