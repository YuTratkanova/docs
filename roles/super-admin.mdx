# Суперадмин (Super Admin)

## Кто это?

**Суперадмин** - это главные администраторы с полным доступом ко всем функциям системы. Суперадмины имеют максимальные права и могут управлять всеми аспектами системы, включая других администраторов.

## Основные функции

Суперадмины имеют **все функции админа** плюс дополнительные возможности:

## Доступ

### Суперадмин панель

Суперадмины имеют доступ ко всем разделам админ-панели плюс дополнительные разделы:

- Все разделы админа
- **Управление админами** - создание и управление администраторами
- **Системные настройки** - критически важные настройки
- **Безопасность** - настройки безопасности
- **Логи системы** - полный доступ к логам

### Полный системный доступ

Суперадмины имеют:
- Полный доступ ко всем API эндпоинтам
- Доступ к системным конфигурациям
- Доступ к базе данных (через API)
- Доступ к логам CloudWatch

## Управление админами

### Создание админа

1. Перейдите в раздел "Админы"
2. Нажмите "Создать админа"
3. Заполните данные:
   - Email
   - Пароль
   - Роль (Admin или Readonly Admin)
4. Сохраните админа

### Управление админами

Суперадмины могут:
- Создавать новых админов
- Редактировать данные админов
- Удалять админов
- Изменять права доступа админов
- Блокировать/разблокировать админов

<Warning>
Удаление или блокировка админа может повлиять на работу системы. Будьте осторожны.
</Warning>

## Настройка безопасности

### Параметры безопасности

Суперадмины могут настраивать:
- Политики паролей
- Настройки сессий
- Настройки токенов
- Ограничения доступа
- IP-фильтрацию

### Аудит безопасности

- Просмотр истории входов
- Просмотр критических операций
- Мониторинг подозрительной активности
- Логи безопасности

## Доступ к системным логам

### CloudWatch

Суперадмины имеют полный доступ к логам CloudWatch:
- Просмотр всех логов
- Поиск по логам
- Экспорт логов
- Настройка алертов

### Логи системы

- Логи API запросов
- Логи операций с балансами
- Логи разрешения споров
- Логи критических операций

Подробнее: [CloudWatch руководство](/support/cloudwatch-guide)

## Конфигурация ролей

### Управление ролями

Суперадмины могут:
- Настраивать права доступа для ролей
- Создавать новые роли (если поддерживается)
- Изменять права существующих ролей
- Управлять иерархией ролей

### Права доступа

- Merchant - права мерчанта
- Trader - права трейдера
- Team Lead - права тимлида
- Admin - права админа
- Super Admin - права суперадмина

## Критические операции

Суперадмины могут выполнять критические операции:

- Массовое изменение статусов заявок
- Массовые операции с балансами
- Изменение системных конфигураций
- Восстановление данных
- Экстренное отключение функций

<Warning>
Критические операции необратимы. Убедитесь, что вы понимаете последствия перед выполнением.
</Warning>
