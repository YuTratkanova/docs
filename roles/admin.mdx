# Админ (Admin)

## Кто это?

**Админ** - это администраторы системы с расширенными правами. Админы управляют всеми аспектами системы, разрешают споры и настраивают конфигурацию.

## Доступ

### Админ-панель

Админы имеют доступ ко всем разделам админ-панели:

1. **Дашборд** - общая статистика и метрики
2. **Заявки (Orders)** - управление всеми заявками
3. **Пользователи** - управление мерчантами, трейдерами, админами
4. **Споры (Disputes)** - разрешение конфликтов
5. **Балансы** - управление балансами пользователей
6. **Выплаты (Payouts)** - управление выплатами трейдерам
7. **Реквизиты** - управление реквизитами
8. **Банки** - настройка банков
9. **Валюты и курсы** - управление валютами и курсами обмена
10. **Статистика** - аналитика и отчеты

### Полный доступ к API

Админы имеют доступ ко всем API эндпоинтам:

- `GET /admin/orders` - управление заявками
- `POST /admin/disputes/{id}/resolve` - разрешение спора
- `GET /admin/stats` - статистика
- И другие административные эндпоинты

Подробнее: [Admin API](/platform/api-admin/orders)

## Управление заявками

### Просмотр заявок

1. Перейдите в раздел "Заявки"
2. Используйте фильтры для поиска:
   - По статусу
   - По мерчанту
   - По трейдеру
   - По дате
   - По сумме
3. Просмотрите детали заявки

### Действия с заявками

Админы могут:
- Просматривать детали заявки
- Отменять заявки
- Изменять статус заявки
- Просматривать логи заявки

## Управление пользователями

### Мерчанты

- Создание новых мерчантов
- Редактирование данных мерчантов
- Назначение групп мерчантов
- Управление настройками мерчантов

### Трейдеры

- Создание новых трейдеров
- Редактирование данных трейдеров
- Назначение тимлидов
- Управление процентами трейдеров
- Управление устройствами трейдеров

### Админы

- Просмотр списка админов
- Создание readonly-админов

## Разрешение споров

### Процесс разрешения спора

1. Перейдите в раздел "Споры"
2. Выберите спор из списка
3. Изучите детали спора:
   - Информация о заявке
   - Логи операций
   - Доказательства от мерчанта
   - Доказательства от трейдера
4. Примите решение:
   - В пользу мерчанта
   - В пользу трейдера
5. Система автоматически обработает решение

### Анализ спора

Для принятия решения админ может:
- Просмотреть логи в CloudWatch
- Проверить баланс пользователей
- Изучить историю операций
- Просмотреть доказательства

Подробнее: [Система споров](/features/disputes)

## Управление балансами

### Просмотр балансов

1. Перейдите в раздел "Балансы"
2. Выберите пользователя
3. Просмотрите:
   - Текущий баланс
   - Замороженный баланс
   - Историю операций

### Операции с балансом

Админы могут:
- Пополнять баланс
- Выводить средства
- Блокировать баланс
- Разблокировать баланс

<Warning>
Будьте осторожны при работе с балансами. Все операции логируются.
</Warning>

## Частые вопросы

<AccordionGroup>
  <Accordion title="Как разрешить спор?">
    Перейдите в раздел "Споры", изучите детали спора и примите решение в пользу одной из сторон.

</AccordionGroup>
