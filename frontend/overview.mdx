# Frontend (Trade-Frontend) - Обзор

Frontend приложение PandaPay Trade Platform построено на React и TypeScript.

## Технологии

  <Card title="React" icon="code">

  </Card>
  <Card title="Tailwind CSS" icon="palette">

  </Card>

  </Card>

## Структура приложения

### Основные модули

- **Pages** - страницы приложения для разных ролей
- **Components** - переиспользуемые компоненты
- **API** - клиенты для работы с API
- **Hooks** - кастомные React хуки
- **Utils** - утилиты и хелперы

## Интерфейсы по ролям

### Админ-панель

Полнофункциональная панель для администраторов:
- Дашборд с статистикой
- Управление заявками
- Управление пользователями
- Разрешение споров
- И многое другое

Подробнее: [Админ-панель](/frontend/admin/dashboard)

### Панель мерчанта

Интерфейс для мерчантов:
- Создание и отслеживание заявок
- Просмотр баланса
- Управление выплатами
- Настройки

Подробнее: [Панель мерчанта](/frontend/merchant/dashboard)

### Панель трейдера

Интерфейс для трейдеров:
- Просмотр доступных заявок
- Управление реквизитами
- Просмотр выплат
- Управление устройствами

Подробнее: [Панель трейдера](/frontend/trader/dashboard)

### Панель тимлида

Интерфейс для тимлидов:
- Управление командой
- Статистика по команде
- Просмотр наград

Подробнее: [Панель тимлида](/frontend/team-lead/dashboard)

### Payment Window

Окно оплаты для интеграции:
- Отображение заявки
- Загрузка скриншотов
- Таймеры и уведомления

Подробнее: [Payment Window](/frontend/payment-window/overview)

## Быстрый старт

### Установка

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

### Сборка для production

```bash
npm run build
```
