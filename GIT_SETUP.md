# Настройка Git для коммита

## Команды для выполнения:

Выполните эти команды в терминале (Git Bash):

```bash
git config --global user.email "your-email@example.com"
git config --global user.name "Your Name"
```

Замените:
- `your-email@example.com` на ваш реальный email
- `Your Name` на ваше имя (например, "Йуля" или "Yuliya")

## После настройки:

```bash
git add .
git commit -m "Add PandaPay documentation"
git push
```
