## Первые шаги

### Для мерчантов

1. **Войдите в систему** используя свои учетные данные
2. **Создайте заявку** через API или админ-панель
3. **Отслеживайте статус** заявки через API или интерфейс
4. **Получайте уведомления** о изменении статуса через callback

Подробнее: [Руководство для мерчантов](/roles/merchant)

### Для трейдеров

1. **Войдите в систему** используя свои учетные данные
2. **Настройте реквизиты** для получения выплат
3. **Просматривайте доступные заявки** в личном кабинете
4. **Принимайте и выполняйте заявки**
5. **Получайте награды** за выполнение

Подробнее: [Руководство для трейдеров](/roles/trader)

### Для админов

1. **Войдите в админ-панель**
2. **Изучите дашборд** с общей статистикой
3. **Управляйте заявками** и пользователями
4. **Разрешайте споры** при необходимости
5. **Настраивайте систему** через раздел настроек

Подробнее: [Руководство для админов](/roles/admin)

## Работа с API

Если вы планируете интегрироваться через API:

1. **Изучите документацию API** в разделе [Backend API](/platform/api-introduction)
2. **Получите токен доступа** через аутентификацию
3. **Используйте Swagger документацию** для тестирования эндпоинтов
4. **Настройте callback** для получения уведомлений

Подробнее: [API документация](/platform/api-introduction)
