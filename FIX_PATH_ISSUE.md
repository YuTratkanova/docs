# Проблема: "Failed to fetch file paths"

## Что делать:

### Вариант 1: Измените путь в настройках

1. В Mintlify Dashboard → Settings → Git settings
2. В поле "Path to directory containing docs.json" 
3. **Вместо `.` (точка) попробуйте:**
   - Оставить **пустым** (удалите точку)
   - Или попробуйте `./` 

### Вариант 2: Проверьте структуру файлов

Убедитесь что в корне репозитория есть:
- `mint.json` ✅ (есть)
- `introduction.mdx` ✅ (есть)
- Все папки на месте

### Вариант 3: Переименуйте mint.json

Mintlify может искать `mintlify.json` или `docs.json`. Попробуйте:

1. Скопируйте содержимое `mint.json`
2. Создайте файл `mintlify.json` с тем же содержимым
3. Закоммитьте и запушьте оба файла

### Вариант 4: Убедитесь что файлы запушены

Проверьте на GitHub:
- Откройте https://github.com/YuTratkanova/docs
- Убедитесь что видны файлы: `mint.json`, `introduction.mdx`, папки `roles/`, `platform/` и т.д.
