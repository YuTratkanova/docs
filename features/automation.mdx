# Автоматизация

PandaPay использует автоматизацию для упрощения работы пользователей и уменьшения необходимости ручного вмешательства.

## Автоматическое завершение заявок

Система автоматически завершает заявки при получении подтверждения от банка.

### Как это работает

<Steps>
<Step title="Трейдер принимает заявку">
  Трейдер принимает заявку и выполняет операцию (перевод средств).
</Step>

<Step title="Банк отправляет уведомление">
  Банк отправляет уведомление о получении платежа в систему PandaPay.
</Step>

<Step title="Система обрабатывает уведомление">
  Система:
  - Проверяет соответствие уведомления заявке
  - Валидирует сумму и реквизиты
  - Обновляет балансы
</Step>

<Step title="Автоматическое завершение">
  Если все проверки пройдены:
  - Заявка автоматически переходит в статус `completed`
  - Начисляется награда трейдеру
  - Мерчант получает callback уведомление
  - Балансы обновляются
</Step>
</Steps>

### Преимущества автоматизации

## Когда автоматизация не срабатывает

Автоматическое завершение может не сработать если:

- Банк не отправил уведомление
- Уведомление пришло с задержкой
- Обнаружены несоответствия в данных
- Система не может однозначно идентифицировать заявку

В таких случаях заявка переходит в статус `disputed` для ручного разрешения админом.

## Автоматическое открытие споров

Система автоматически открывает споры при:

- Отсутствии подтверждения платежа в течение определенного времени
- Обнаружении несоответствий в данных
- Технических ошибках при обработке

## Автоматическое начисление наград

После автоматического завершения заявки:
- Трейдеру автоматически начисляется награда
- Рассчитывается комиссия
- Обновляются балансы

## Автоматические уведомления

Система автоматически отправляет уведомления при:
- Изменении статуса заявки
- Открытии спора
- Начислении выплаты
- Критических событиях

Подробнее: [Уведомления](/features/notifications)

## Мониторинг автоматизации

### Для админов

Админы могут отслеживать:
- Количество автоматически завершенных заявок
- Процент успешных автоматизаций
- Логи автоматических операций

### CloudWatch логи

Все автоматические операции логируются в CloudWatch для мониторинга и отладки.

Подробнее: [CloudWatch руководство](/support/cloudwatch-guide)

## Настройка автоматизации

Автоматизация настраивается администраторами через системные конфигурации:
- Время ожидания подтверждения от банка
- Пороги для автоматического открытия споров
- Правила автоматического завершения

<Info>
Настройки автоматизации влияют на работу всей системы. Изменения должны выполняться только администраторами.
</Info>

## Частые вопросы

<AccordionGroup>
  <Accordion title="Почему заявка не завершилась автоматически?">
    Возможные причины: банк не отправил уведомление, обнаружены несоответствия в данных, или превышено время ожидания. Обратитесь к админу для проверки.
  </Accordion>
  <Accordion title="Сколько времени ждет система перед автоматическим завершением?">
    Обычно 5-15 минут после выполнения операции трейдером, в зависимости от настроек системы.
  </Accordion>
  <Accordion title="Можно ли отключить автоматизацию?">
    Автоматизация является ключевой функцией системы и не может быть отключена полностью. Настройки могут быть изменены администраторами.
  </Accordion>
</AccordionGroup>
