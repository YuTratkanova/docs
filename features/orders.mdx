# Система заявок (Orders)

Система заявок - это основа платформы PandaPay. Заявки создаются мерчантами и выполняются трейдерами.

## Жизненный цикл заявки

```
1. Мерчант создает заявку
   ↓
2. Система ищет подходящего трейдера
   ↓
3. Трейдер принимает заявку (pending → accepted)
   ↓
4. Трейдер выполняет операцию
   ↓
5. Система автоматически завершает заявку (accepted → completed)
   ИЛИ
   Открывается спор (accepted → disputed)
```

## Создание заявки

### Через API

```bash
POST /order
{
  "amount": 1000,
  "currency": "USD",
  "callback_url": "https://your-site.com/callback"
}
```

### Через админ-панель

1. Войдите в админ-панель
2. Перейдите в раздел "Заявки"
3. Нажмите "Создать заявку"
4. Заполните необходимые поля

## Автоматическое завершение

Система автоматически завершает заявки при получении подтверждения от банка:

1. Банк отправляет уведомление о платеже
2. Система обрабатывает уведомление
3. Заявка автоматически переходит в статус `completed`
4. Мерчант получает callback уведомление

Подробнее: [Автоматизация](/features/automation)

## Споры

Спор открывается автоматически когда:
- Мерчант не получил оплату в течение определенного времени
- Трейдер не может подтвердить выполнение
- Обнаружены несоответствия в данных

Разрешение споров выполняется администратором.

Подробнее: [Система споров](/features/disputes)

## Отмена заявки

Заявка может быть отменена:
- Автоматически по истечении времени ожидания
- Вручную мерчантом (если разрешено)
- Вручную администратором

## Уведомления

При изменении статуса заявки отправляются уведомления:
- **Callback** - webhook на URL мерчанта
- **Email** - уведомление на email
- **Telegram** - уведомление трейдеру (если настроено)

Подробнее: [Уведомления](/features/notifications)
