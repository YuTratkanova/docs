# Управление реквизитами

Система реквизитов позволяет трейдерам хранить и управлять банковскими реквизитами для получения выплат.

## Что такое реквизит

Реквизит - это банковский счет или платежная система, которую трейдер использует для получения выплат за выполнение заявок.

## Добавление реквизита

### Через интерфейс трейдера

<Steps>
<Step title="Перейдите в раздел Реквизиты">
  В личном кабинете трейдера выберите раздел "Реквизиты".
</Step>

<Step title="Нажмите 'Добавить реквизит'">
  Заполните форму с данными реквизита:
  
  - **Банк** - выберите из списка
  - **Номер счета** - введите номер счета
  - **Валюта** - выберите валюту реквизита
  - **Страна** - выберите страну
  - **Дополнительные данные** (если требуется)
</Step>

<Step title="Сохраните реквизит">
  После заполнения нажмите "Сохранить". Система автоматически проверит реквизит на валидность.
</Step>
</Steps>

### Валидация реквизитов

Система проверяет реквизиты при добавлении:
- Формат номера счета
- Соответствие валюте и стране
- Другие требования валидации

<Warning>
Убедитесь, что реквизит корректен перед сохранением. Некорректные реквизиты могут привести к проблемам с выплатами.
</Warning>

## Требования к реквизитам

### Обязательные поля

- Банк
- Номер счета
- Валюта
- Страна

### Дополнительные поля

- Название счета (для удобства)
- IBAN (если применимо)
- SWIFT/BIC код (если требуется)

## Использование реквизитов

### Фильтрация по реквизитам

При поиске заявок система автоматически фильтрует заявки, которые могут быть выполнены с использованием доступных реквизитов трейдера.

### Автоматический выбор

Система выбирает подходящий реквизит на основе:
- Валюты заявки
- Страны заявки
- Доступности реквизита

## Управление реквизитами

### Редактирование

Трейдеры могут редактировать свои реквизиты:
- Изменять данные
- Обновлять статус (активен/неактивен)
- Добавлять комментарии

### Деактивация

Реквизиты можно деактивировать без удаления:
- Сохраняется история использования
- Не используется для новых заявок
- Можно активировать снова

## Для админов

Админы могут:
- Просматривать все реквизиты всех трейдеров
- Управлять реквизитами
- Проверять валидность
- Блокировать реквизиты при необходимости

Подробнее: [Управление реквизитами в админке](/frontend/admin/requisites)

## API для работы с реквизитами

### Получить список реквизитов

```bash
GET /trader/requisites
Authorization: Bearer {token}
```

### Добавить реквизит

```bash
POST /trader/requisites
Authorization: Bearer {token}
Content-Type: application/json

{
  "bank_id": "bank_123",
  "account_number": "1234567890",
  "currency": "USD",
  "country": "USA"
}
```

Подробнее: [Trader API - Реквизиты](/platform/api-trader/requisites)

## Частые вопросы

<AccordionGroup>
  <Accordion title="Сколько реквизитов можно добавить?">
    Нет ограничения на количество реквизитов. Трейдер может добавить столько реквизитов, сколько необходимо для работы.
  </Accordion>
  <Accordion title="Что делать если реквизит не проходит валидацию?">
    Проверьте правильность введенных данных. Если ошибка сохраняется, обратитесь в техподдержку или к администратору.
  </Accordion>
  <Accordion title="Можно ли изменить реквизит после добавления?">
    Да, реквизиты можно редактировать в любое время через раздел "Реквизиты" в личном кабинете.
  </Accordion>
</AccordionGroup>
