# Система споров (Disputes)

Система споров позволяет разрешать конфликты между мерчантами и трейдерами при проблемах с выполнением заявок.

## Когда открывается спор

Спор открывается автоматически или вручную в следующих случаях:

<CardGroup cols={2}>
  <Card title="Автоматическое открытие" icon="alert-circle">
    - Мерчант не получил оплату в течение определенного времени
    - Обнаружены несоответствия в данных заявки
    - Система не может автоматически завершить заявку
  </Card>
  <Card title="Ручное открытие" icon="user">
    - Мерчант сообщает о проблеме
    - Трейдер не может подтвердить выполнение
    - Администратор открывает спор для расследования
  </Card>
</CardGroup>

## Статусы спора

- `active` - спор открыт, ожидает разрешения
- `paused` - спор приостановлен (ожидание дополнительной информации)
- `resolved` - спор разрешен, решение принято
- `closed` - спор закрыт

## Процесс разрешения спора

<Steps>
<Step title="Открытие спора">
  Система или пользователь открывает спор при обнаружении проблемы.
  
  При открытии спора:
  - Баланс может быть заморожен
  - Заявка переходит в статус `disputed`
  - Отправляются уведомления участникам
</Step>

<Step title="Анализ спора">
  Администратор изучает:
  - Детали заявки
  - Логи операций
  - Доказательства от мерчанта и трейдера
  - Балансы пользователей
  - CloudWatch логи
  
  <Info>
  Админы могут просматривать полные логи через раздел "Споры" в админ-панели.
  </Info>
</Step>

<Step title="Принятие решения">
  Администратор принимает решение:
  
  - **В пользу мерчанта** - средства возвращаются мерчанту
  - **В пользу трейдера** - средства остаются у трейдера
  - **Частичное решение** - средства распределяются между сторонами
</Step>

<Step title="Обработка решения">
  После принятия решения:
  - Система автоматически обрабатывает переводы средств
  - Балансы размораживаются
  - Заявка переходит в финальный статус
  - Участники получают уведомления
</Step>
</Steps>

## Разрешение споров для админов

### Просмотр спора

1. Перейдите в раздел "Споры" в админ-панели
2. Выберите спор из списка
3. Изучите детали:
   - Информация о заявке
   - Логи операций
   - Доказательства
   - История изменений

### Принятие решения

1. Изучите все материалы спора
2. Примите решение:
   - В пользу мерчанта
   - В пользу трейдера
   - Частичное решение
3. Система автоматически обработает финансовые операции

### Полезные инструменты

- **CloudWatch логи** - детальные логи всех операций
- **История балансов** - просмотр всех финансовых операций
- **Детали заявки** - полная информация о заявке

Подробнее: [Разрешение споров для админов](/roles/admin)

## Автоматическое разрешение

Система может автоматически разрешать споры в простых случаях:
- При получении подтверждения от банка
- При обнаружении технических ошибок
- При автоматическом обнаружении решения

<Info>
Большинство споров требуют ручного разрешения администратором для обеспечения справедливости.
</Info>

## Частые вопросы

<AccordionGroup>
  <Accordion title="Как открыть спор?">
    Обратитесь к администратору или используйте соответствующую функцию в интерфейсе. Споры также открываются автоматически при обнаружении проблем.
  </Accordion>
  <Accordion title="Сколько времени занимает разрешение спора?">
    Обычно 24-48 часов в зависимости от сложности ситуации. Приостановленные споры могут занимать больше времени.
  </Accordion>
  <Accordion title="Что происходит с балансом во время спора?">
    Замороженный баланс может быть заблокирован до разрешения спора для обеспечения справедливого решения.
  </Accordion>
</AccordionGroup>
