# Система балансов

Система балансов позволяет отслеживать все финансовые операции пользователей в платформе PandaPay.

## Состояния баланса

### Текущий баланс

Баланс, доступный для операций. Используется при создании заявок и выводе средств.

### Замороженный баланс

Баланс, заблокированный системой или администратором:
- При открытии спора
- При подозрительных операциях
- По решению администратора

<Warning>
Замороженный баланс недоступен для операций до разблокировки.
</Warning>

## Просмотр баланса

### Для мерчантов

```bash
GET /balance
Authorization: Bearer {token}
```

### Для трейдеров

Баланс отображается в личном кабинете с разбивкой:
- Доступный баланс
- Замороженный баланс
- Общий баланс

### Для админов

Админы могут просматривать баланс любого пользователя через админ-панель или API.

## История операций

Все операции записываются в `balance_history` с информацией:
- Тип операции
- Сумма
- Валюта
- Дата и время
- Связанная заявка (если применимо)
- Комментарий

### Просмотр истории

```bash
GET /balance/history
Authorization: Bearer {token}
```

Подробнее: [Баланс в API](/platform/api-merchant/balance)

## Управление балансом

### Пополнение баланса

Админы могут пополнять баланс пользователей через админ-панель или API.

### Вывод средств

Пользователи могут выводить средства, если:
- Баланс достаточен
- Баланс не заморожен
- Нет открытых споров

### Блокировка баланса

Админы могут блокировать баланс при:
- Подозрительной активности
- Открытии спора
- Нарушении правил

<Warning>
Блокировка баланса влияет на все последующие операции. Используйте с осторожностью.
</Warning>

## Частые вопросы

<AccordionGroup>
  <Accordion title="Почему баланс заморожен?">
    Баланс может быть заморожен при открытии спора, подозрительной активности или по решению администратора. Проверьте статус споров и обратитесь к админу.

  <Accordion title="Как проверить историю операций?">
    Используйте API эндпоинт `GET /balance/history` или просмотрите в личном кабинете в разделе "История баланса".
  </Accordion>
  <Accordion title="Когда начисляется награда трейдеру?">
    Награда начисляется автоматически после успешного завершения заявки. Проверить можно в истории операций.
  </Accordion>
</AccordionGroup>
