## Способ 2: Через API

### Для мерчанта (свой баланс)

```bash
GET /balance
Authorization: Bearer {merchant_token}
```

**Пример:**
```bash
curl -X GET "https://api.pandapay.com/balance" \
  -H "Authorization: Bearer MERCHANT_TOKEN"
```

**Ответ:**
```json
{
  "balance": 10000.50,
  "currency": "USD",
  "frozen_balance": 500.00,
  "total_balance": 10500.50
}
```

### Для админа (любой пользователь)

```bash
GET /admin/users/{user_id}/balance
Authorization: Bearer {admin_token}
```

**Пример:**
```bash
curl -X GET "https://api.pandapay.com/admin/users/123/balance" \
  -H "Authorization: Bearer ADMIN_TOKEN"
```

Подробнее: [Merchant API - Баланс](/platform/api-merchant/balance)

## Способ 3: История операций

### Через API

Получить историю операций с балансом:

```bash
GET /balance/history
Authorization: Bearer {token}
```

**Параметры:**
- `limit` - количество записей
- `offset` - смещение для пагинации
- `type` - тип операции (order, payout, topUp, etc.)

**Пример:**
```bash
curl -X GET "https://api.pandapay.com/balance/history?limit=10&type=order" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

**Ответ:**
```json
{
  "history": [
    {
      "id": "op_123",
      "type": "order",
      "amount": -1000.00,
      "balance_before": 11000.50,
      "balance_after": 10000.50,
      "currency": "USD",
      "created_at": "2024-01-18T10:00:00Z",
      "order_id": "order_abc123"
    }
  ],
  "total": 150
}
```

## Что проверить при проблемах с балансом

### Баланс не обновляется

1. **Проверьте историю операций** - была ли операция создана
2. **Проверьте статус заявки** - заявка должна быть в правильном статусе
3. **Проверьте логи** - есть ли ошибки в CloudWatch

### Баланс заморожен

1. **Проверьте активные споры** - баланс замораживается при спорах
2. **Обратитесь к админу** - админ может заморозить баланс вручную
3. **Проверьте историю** - найдите операцию типа `block`

### Несоответствие баланса

1. **Проверьте все операции** - просмотрите полную историю
2. **Сравните с заявками** - проверьте что все заявки учтены
3. **Используйте CloudWatch** - проверьте логи операций с балансом

Подробнее: [Система балансов](/features/balances)

## Для администраторов

### Управление балансом

Админы могут:
- Пополнять баланс пользователей
- Замораживать/размораживать баланс
- Просматривать историю операций любого пользователя
- Анализировать операции

### Проверка через админ-панель

1. Перейдите в **Балансы**
2. Найдите пользователя
3. Просмотрите детали:
   - Текущий баланс
   - Замороженный баланс
   - История операций
   - Связанные заявки

## Частые вопросы

<AccordionGroup>
  <Accordion title="Почему баланс заморожен?">
    Баланс замораживается при открытии спора, подозрительной активности или по решению администратора. Проверьте активные споры и обратитесь к админу.
  </Accordion>
  <Accordion title="Как узнать почему баланс изменился?">
    Проверьте историю операций через API `/balance/history` или в админ-панели. Каждая операция содержит информацию о причине изменения.
  </Accordion>
  <Accordion title="Баланс не совпадает с ожидаемым">
    Проверьте историю операций, убедитесь что все заявки учтены. Если проблема сохраняется, обратитесь к администратору с историей операций.
  </Accordion>
</AccordionGroup>
