# Часто задаваемые вопросы (FAQ)

## Общие вопросы

<AccordionGroup>
  <Accordion title="Что такое PandaPay Trade Platform?">
    PandaPay Trade Platform - это платформа для торговых операций, которая связывает мерчантов, трейдеров и администраторов. Подробнее в разделе [Введение](/introduction).
  </Accordion>
  <Accordion title="Какие роли есть в системе?">
    В системе 5 основных ролей: Мерчант, Трейдер, Тимлид, Админ и Суперадмин. Подробнее в разделе [Роли и пользователи](/roles/merchant).
  </Accordion>
  <Accordion title="Как получить доступ к системе?">
    Обратитесь к администратору для получения доступа. Для тестирования можно использовать тестовые аккаунты из раздела [Быстрый старт](/quickstart).
  </Accordion>
</AccordionGroup>

## Вопросы о заявках

<AccordionGroup>
  <Accordion title="Как создать заявку?">
    Заявку можно создать через API эндпоинт `POST /order` или через админ-панель в разделе "Заявки". Подробнее в разделе [Система заявок](/features/orders).
  </Accordion>
  <Accordion title="Как отследить статус заявки?">
    Используйте эндпоинт `GET /order/{id}` или настройте callback для автоматических уведомлений. Также можно просмотреть заявку в админ-панели.
  </Accordion>
  <Accordion title="Как работает автоматическое завершение заявок?">
    Система отслеживает уведомления от банков и автоматически завершает заявки при получении подтверждения. Подробнее в разделе [Автоматизация](/features/automation).
  </Accordion>
  <Accordion title="Что делать, если заявка в споре?">
    Обратитесь к администратору. Админ изучит детали спора и примет решение. Подробнее в разделе [Система споров](/features/disputes).
  </Accordion>
</AccordionGroup>

## Вопросы о балансе

<AccordionGroup>
  <Accordion title="Как проверить баланс?">
    Используйте API эндпоинт `GET /balance` или просмотрите баланс в личном кабинете. Админы могут проверить баланс любого пользователя через админ-панель.
  </Accordion>
  <Accordion title="Почему баланс заморожен?">
    Баланс может быть заморожен при открытии спора или по решению администратора. Проверьте статус заявок и споров.
  </Accordion>
  <Accordion title="Как пополнить баланс?">
    Обратитесь к администратору для пополнения баланса. Админы могут пополнять баланс через админ-панель.
  </Accordion>
</AccordionGroup>

## Вопросы для трейдеров

<AccordionGroup>
  <Accordion title="Как получить уведомления о новых заявках?">
    Подключите Telegram бота в настройках и укажите ваш Telegram User ID. Подробнее в разделе [Трейдер](/roles/trader).
  </Accordion>
  <Accordion title="Как добавить реквизит?">
    Перейдите в раздел "Реквизиты" и нажмите "Добавить реквизит". Заполните все необходимые поля. Подробнее в разделе [Управление реквизитами](/features/requisites).
  </Accordion>
  <Accordion title="Когда я получу выплату?">
    Выплаты начисляются автоматически после завершения заявки. Просмотреть выплаты можно в разделе "Выплаты".
  </Accordion>
</AccordionGroup>

## Вопросы для админов

<AccordionGroup>
  <Accordion title="Как разрешить спор?">
    Перейдите в раздел "Споры", изучите детали спора и примите решение в пользу одной из сторон. Подробнее в разделе [Админ](/roles/admin).
  </Accordion>
  <Accordion title="Как проверить логи заявки?">
    В деталях заявки есть ссылка на логи в CloudWatch. Также можно использовать раздел "Статистика" для поиска логов. Подробнее в разделе [CloudWatch руководство](/support/cloudwatch-guide).
  </Accordion>
  <Accordion title="Как найти информацию о заявке?">
    Используйте API эндпоинт `GET /order/{id}` или найдите заявку в админ-панели через поиск по ID или фильтры.
  </Accordion>
</AccordionGroup>

## Технические вопросы

<AccordionGroup>
  <Accordion title="Как интегрироваться через API?">
    Изучите документацию API в разделе [Backend API](/platform/api-introduction). Получите токен доступа и начните использовать эндпоинты.
  </Accordion>
  <Accordion title="Как настроить callback?">
    Укажите `callback_url` при создании заявки. Система будет отправлять POST запросы на этот URL при изменении статуса заявки. Подробнее в разделе [Callbacks](/platform/api-merchant/callbacks).
  </Accordion>
  <Accordion title="Где найти Swagger документацию?">
    Swagger документация доступна в файле `swagger.yaml` в репозитории или через [Swagger Editor](https://editor.swagger.io/).
  </Accordion>
</AccordionGroup>
