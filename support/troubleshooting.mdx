# Решение проблем

Руководство по решению наиболее распространенных проблем в системе PandaPay.

## Общие проблемы

### Не могу войти в систему

<AccordionGroup>
  <Accordion title="Неверный email или пароль">
    **Решение:**
    - Проверьте правильность введенных данных
    - Убедитесь что Caps Lock выключен
    - Используйте тестовые аккаунты для проверки:
      - Админ: `test-admin@poroxis.com`
      - Трейдер: `test-trader@poroxis.com`
      - Мерчант: `test-merchant@poroxis.com`
  </Accordion>

  <Accordion title="Аккаунт заблокирован">
    **Решение:**
    - Обратитесь к администратору для разблокировки
    - Проверьте email на наличие уведомлений о блокировке
  </Accordion>
</AccordionGroup>

### Проблемы с API

<AccordionGroup>
  <Accordion title="Ошибка 401 Unauthorized">
    **Причина:** Неверный или истекший токен авторизации
    
    **Решение:**
    - Проверьте правильность токена
    - Обновите токен через `/auth/login`
    - Убедитесь что токен передается в заголовке `Authorization: Bearer {token}`
  </Accordion>

  <Accordion title="Ошибка 403 Forbidden">
    **Причина:** Недостаточно прав для выполнения операции
    
    **Решение:**
    - Проверьте роль пользователя
    - Убедитесь что используете правильные эндпоинты для вашей роли
    - Обратитесь к администратору для проверки прав
  </Accordion>

  <Accordion title="Ошибка 404 Not Found">
    **Причина:** Неверный URL или ресурс не существует
    
    **Решение:**
    - Проверьте правильность URL эндпоинта
    - Убедитесь что используете правильную версию API
    - Проверьте документацию API
  </Accordion>
</AccordionGroup>

## Проблемы с заявками

### Заявка не создается

**Возможные причины:**
- Недостаточно средств на балансе мерчанта
- Неверные параметры заявки
- Ошибки валидации данных

**Решение:**
- Проверьте баланс мерчанта
- Проверьте все обязательные поля
- Используйте Swagger для проверки формата запроса

### Заявка зависла в статусе

**Решение:**
- Проверьте логи в CloudWatch
- Обратитесь к администратору для проверки заявки
- Проверьте связанные споры

Подробнее: [Как найти заявку](/support/how-to-find-order)

## Проблемы с балансом

### Баланс не обновляется

**Решение:**
- Проверьте историю операций через API
- Убедитесь что операция была выполнена успешно
- Проверьте статус заявок

### Баланс заморожен

**Причины:**
- Открыт активный спор
- Подозрительная активность
- Решение администратора

**Решение:**
- Проверьте активные споры
- Обратитесь к администратору
- Предоставьте необходимые доказательства

Подробнее: [Как проверить баланс](/support/how-to-check-balance)

## Проблемы с уведомлениями

### Не приходят Telegram уведомления

**Решение:**
- Проверьте что Telegram User ID указан в настройках
- Убедитесь что бот подключен ([@pandapay24_bot](https://t.me/pandapay24_bot))
- Проверьте что уведомления не отключены в настройках

### Не работает Callback

**Решение:**
- Проверьте доступность вашего сервера извне
- Убедитесь что `callback_url` правильный и доступен
- Проверьте логи вашего сервера
- Используйте инструменты вроде ngrok для тестирования

Подробнее: [Уведомления](/features/notifications)

## Проблемы с выплатами

### Выплата не пришла

**Решение:**
- Проверьте статус выплаты через API или админ-панель
- Убедитесь что реквизиты корректны
- Проверьте баланс трейдера
- Обратитесь к администратору

### Некорректные реквизиты

**Решение:**
- Проверьте данные реквизита
- Убедитесь что реквизит прошел валидацию
- Обновите реквизит если необходимо

## Работа с логами

### CloudWatch логи

Для диагностики проблем используйте CloudWatch логи:

1. Войдите в AWS Console
2. Перейдите в CloudWatch → Logs
3. Найдите логи вашего сервиса
4. Фильтруйте по времени и ключевым словам

Подробнее: [Руководство по CloudWatch](/support/cloudwatch-guide)

## Обращение в техподдержку

### Что нужно предоставить

При обращении в техподдержку предоставьте:

- **Описание проблемы** - детальное описание что не работает
- **Шаги воспроизведения** - что вы делали когда возникла проблема
- **ID заявки/операции** - если проблема связана с конкретной операцией
- **Логи** - если доступны (CloudWatch, API ответы)
- **Временная метка** - когда произошла проблема
- **Скриншоты** - если применимо

### Контакты техподдержки

- Email: support@pandapay.com
- Через админ-панель: раздел "Техподдержка"
- Telegram: [@pandapay24_bot](https://t.me/pandapay24_bot) (для трейдеров)
