# Как найти заявку

Пошаговые инструкции по поиску заявки в системе PandaPay.

## Способ 1: Через админ-панель

<Steps>
<Step title="Войдите в админ-панель">
  Используйте аккаунт администратора:
  - Email: `test-admin@poroxis.com`
  - Пароль: `R4IhCX#axlf@`
</Step>

<Step title="Перейдите в раздел 'Заявки'">
  В левом меню выберите раздел **"Заявки"** (Orders).
</Step>

<Step title="Используйте поиск">
  Если у вас есть ID заявки:
  - Введите ID в поле поиска
  - Нажмите "Поиск"
  
  Если ID нет, используйте фильтры:
  - По дате создания
  - По статусу
  - По мерчанту или трейдеру
  - По сумме
</Step>

<Step title="Просмотрите результаты">
  В списке результатов найдите нужную заявку и нажмите на неё для просмотра деталей.
</Step>
</Steps>

## Способ 2: Через API

### Если известен ID заявки

```bash
GET /order/{order_id}
Authorization: Bearer {token}
```

**Пример:**
```bash
curl -X GET "https://api.pandapay.com/order/order_abc123" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

### Поиск по параметрам

```bash
GET /orders?merchant_id=123&status=completed
Authorization: Bearer {token}
```

**Параметры поиска:**
- `merchant_id` - ID мерчанта
- `trader_id` - ID трейдера
- `status` - статус заявки
- `amount` - сумма
- `date_from` - дата начала
- `date_to` - дата окончания

**Пример:**
```bash
curl -X GET "https://api.pandapay.com/orders?merchant_id=123&status=active" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

Подробнее: [API документация](/platform/api-introduction)

## Способ 3: Через CloudWatch логи

Если заявка была создана недавно, можно найти её в логах:

<Steps>
<Step title="Откройте CloudWatch">
  В AWS Console перейдите в CloudWatch → Logs → Log groups.
</Step>

<Step title="Выберите временной диапазон">
  Выберите время, когда была создана заявка.
</Step>

<Step title="Используйте фильтр">
  Если знаете ID заявки:
  ```
  order_id:YOUR_ORDER_ID
  ```
  
  Если знаете ID мерчанта или трейдера:
  ```
  merchant_id:123
  trader_id:456
  ```
</Step>

<Step title="Просмотрите логи">
  В логах вы найдете информацию о создании и обработке заявки.
</Step>
</Steps>

Подробнее: [Руководство по CloudWatch](/support/cloudwatch-guide)

## Поиск по разным критериям

### По ID заявки

Самый быстрый способ, если знаете ID:
- В админ-панели: введите ID в поиск
- Через API: `GET /order/{id}`

### По мерчанту

Если нужно найти все заявки мерчанта:
- В админ-панели: фильтр по мерчанту
- Через API: `GET /orders?merchant_id={id}`

### По трейдеру

Если нужно найти заявки трейдера:
- В админ-панели: фильтр по трейдеру
- Через API: `GET /orders?trader_id={id}`

### По статусу

Если нужно найти заявки определенного статуса:
- `pending` - ожидающие принятия
- `active` - в процессе выполнения
- `completed` - завершенные
- `cancelled` - отмененные
- `disputed` - в споре

### По дате

Используйте фильтр по дате:
- `date_from` - с даты
- `date_to` - до даты

## Если заявку не удается найти

<Warning>
Если заявку не удается найти, возможно:
- Заявка была удалена (удаленные заявки обычно не отображаются)
- Заявка создана в другом окружении (dev/prod)
- У вас нет прав для просмотра этой заявки
</Warning>

### Что проверить

1. **Правильность ID** - убедитесь что ID введен правильно
2. **Права доступа** - проверьте что у вас есть права для просмотра заявок
3. **Окружение** - убедитесь что ищете в правильном окружении (dev/prod)
4. **Временной диапазон** - расширьте диапазон поиска по дате

### Альтернативные способы

- Проверьте **историю баланса** - там могут быть записи об операциях
- Проверьте **CloudWatch логи** - поиск по времени создания
- Обратитесь к **администратору** - если заявка важна
