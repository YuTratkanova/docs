# Типичные проблемы

Список самых частых проблем и их быстрых решений.

## Аутентификация и доступ

<Tip>
**Проблема:** Не могу войти в систему

**Решение:**
- Используйте тестовые аккаунты для проверки:
  - Админ: `test-admin@poroxis.com` / `R4IhCX#axlf@`
  - Трейдер: `test-trader@poroxis.com` / `R4IhCX#axlf@`
  - Мерчант: `test-merchant@poroxis.com` / `R4IhCX#axlf@`
- Проверьте правильность email и пароля
- Очистите кеш браузера
</Tip>

<Tip>
**Проблема:** API возвращает 401 Unauthorized

**Решение:**
- Обновите токен через `/auth/login`
- Проверьте формат заголовка: `Authorization: Bearer {token}`
- Убедитесь что токен не истек
</Tip>

## Заявки (Orders)

<Tip>
**Проблема:** Не могу создать заявку - ошибка валидации

**Решение:**
- Проверьте все обязательные поля
- Убедитесь что сумма положительная
- Проверьте что валюта поддерживается
- Используйте Swagger для проверки формата
</Tip>

<Tip>
**Проблема:** Заявка не завершается автоматически

**Решение:**
- Проверьте логи в CloudWatch
- Убедитесь что банк отправил уведомление
- Обратитесь к админу - возможно требуется ручное завершение
- Проверьте статус заявки
</Tip>

<Tip>
**Проблема:** Не вижу заявки в списке

**Решение:**
- Проверьте фильтры поиска
- Убедитесь что используете правильные параметры поиска
- Проверьте права доступа - возможно заявки принадлежат другому пользователю
</Tip>

## Балансы

<Tip>
**Проблема:** Баланс не обновляется после операции

**Решение:**
- Проверьте историю операций через API `/balance/history`
- Убедитесь что операция была успешной
- Проверьте что заявка в правильном статусе
- Обратитесь к админу для проверки
</Tip>

<Tip>
**Проблема:** Баланс заморожен, не могу вывести средства

**Решение:**
- Проверьте активные споры - баланс замораживается при спорах
- Обратитесь к администратору
- Предоставьте необходимую информацию для разблокировки
</Tip>

## Выплаты

<Tip>
**Проблема:** Выплата не пришла на счет

**Решение:**
- Проверьте статус выплаты через API или админ-панель
- Убедитесь что реквизиты корректны
- Проверьте что реквизит прошел валидацию
- Обратитесь к админу с ID выплаты
</Tip>

<Tip>
**Проблема:** Не могу добавить реквизит - ошибка валидации

**Решение:**
- Проверьте формат номера счета
- Убедитесь что валюта и страна соответствуют банку
- Проверьте все обязательные поля
- Попробуйте другой банк если проблема сохраняется
</Tip>

## Уведомления

<Tip>
**Проблема:** Не приходят Telegram уведомления

**Решение:**
- Убедитесь что Telegram User ID указан в настройках
- Подключите бота [@pandapay24_bot](https://t.me/pandapay24_bot)
- Проверьте что уведомления включены в настройках
- Получите ваш User ID через @userinfobot
</Tip>

<Tip>
**Проблема:** Callback не приходит на мой сервер

**Решение:**
- Проверьте доступность `callback_url` извне (используйте ngrok для тестирования)
- Проверьте логи вашего сервера
- Убедитесь что сервер отвечает на POST запросы
- Проверьте правильность формата callback URL
</Tip>

## Споры (Disputes)

<Tip>
**Проблема:** Как разрешить спор в пользу мерчанта?

**Решение:**
- В админ-панели перейдите в раздел "Споры"
- Изучите детали спора, логи и доказательства
- Примите решение "В пользу мерчанта"
- Система автоматически обработает возврат средств
</Tip>

<Tip>
**Проблема:** Спор открыт, но я не вижу деталей

**Решение:**
- Обратитесь к администратору
- Проверьте уведомления - должны были прийти детали спора
- Проверьте раздел "Споры" в личном кабинете
</Tip>

## Технические проблемы

<Tip>
**Проблема:** API медленно отвечает

**Решение:**
- Проверьте статус сервисов на AWS
- Проверьте CloudWatch метрики
- Проверьте количество активных запросов
- Обратитесь к техподдержке если проблема сохраняется
</Tip>

<Tip>
**Проблема:** Ошибка при обработке запроса

**Решение:**
- Проверьте формат запроса через Swagger
- Убедитесь что все обязательные поля присутствуют
- Проверьте типы данных (строки, числа, даты)
- Используйте логи для диагностики
</Tip>

## Работа с админ-панелью

<Tip>
**Проблема:** Не вижу некоторые разделы в админ-панели

**Решение:**
- Проверьте права доступа - некоторые разделы доступны только суперадминам
- Убедитесь что используете правильный аккаунт
- Обратитесь к суперадмину для проверки прав
</Tip>

<Tip>
**Проблема:** Не могу редактировать настройки пользователя

**Решение:**
- Проверьте что у вас есть права администратора или суперадмина
- Убедитесь что пользователь не заблокирован
- Попробуйте обновить страницу
</Tip>
