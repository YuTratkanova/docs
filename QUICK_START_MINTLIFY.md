# Пошаговая инструкция: Настройка Mintlify

## Шаг 1: Откройте Settings (Настройки)

В левом боковом меню найдите и нажмите на **"Settings"** (Настройки).

---

## Шаг 2: Найдите раздел "Repository" (Репозиторий)

В настройках найдите раздел про подключение репозитория GitHub.

---

## Шаг 3: Измените репозиторий (если нужно)

Если сейчас подключен репозиторий `yutratkanova / docs`, а ваша документация находится в другом репозитории:

1. Найдите кнопку **"Change Repository"** или **"Edit"** рядом с репозиторием
2. Выберите правильный репозиторий (где находится папка `PandaPay` с документацией)

---

## Шаг 4: Укажите путь к документации

Найдите поле **"Repository Path"** или **"Docs Path"**.

**В это поле нужно ввести:** `docs/`

Это означает, что документация находится в папке `docs/` внутри репозитория.

---

## Шаг 5: Сохраните настройки

Нажмите кнопку **"Save"** или **"Update"** внизу страницы настроек.

---

## Шаг 6: Добавьте API ключ в GitHub Secrets

1. **Откройте ваш репозиторий PandaPay на GitHub**
2. Перейдите в **Settings** (Настройки репозитория)
3. В левом меню найдите **"Secrets and variables"** → **"Actions"**
4. Нажмите **"New repository secret"**
5. В поле **Name** введите: `MINTLIFY_API_KEY`
6. В поле **Value** вставьте API ключ из Mintlify:
   - Вернитесь в Mintlify Dashboard
   - Перейдите в Settings
   - Найдите раздел "API" или "API Key"
   - Скопируйте ключ
   - Вставьте в GitHub Secrets
7. Нажмите **"Add secret"**

---

## Шаг 7: Вернитесь в Mintlify и обновите документацию

В Mintlify Dashboard:

1. Вернитесь на главную страницу (Overview)
2. Нажмите кнопку **"Visit site"** чтобы посмотреть документацию
3. Или нажмите кнопку обновления (иконка обновления рядом с "Visit site")

---

## Что должно получиться:

- ✅ Репозиторий: ваш репозиторий PandaPay
- ✅ Repository Path: `docs/`
- ✅ Branch: `main` (или `master`)
- ✅ API ключ добавлен в GitHub Secrets

После этого документация будет автоматически обновляться при каждом push в репозиторий!

---

## Если что-то не работает:

1. **Документация не появляется:**
   - Проверьте, что путь `docs/` указан правильно
   - Убедитесь, что в папке `docs/` есть файл `mint.json`

2. **GitHub Actions не запускается:**
   - Проверьте, что файл `.github/workflows/mintlify-deploy.yml` существует
   - Проверьте, что `MINTLIFY_API_KEY` добавлен в Secrets

3. **Swagger не подключается:**
   - Временно можно пропустить - документация будет работать без Swagger

---

**Главное:** Найдите в Settings поле **"Repository Path"** и введите туда `docs/` ✨
