# PandaPay Trade Platform

Добро пожаловать в документацию платформы **PandaPay Trade Platform**!

PandaPay Trade Platform - это комплексная платформа для торговых операций, которая связывает мерчантов, трейдеров и администраторов в единой экосистеме.

## Что такое PandaPay?

PandaPay - это платформа, которая обеспечивает:

- **Автоматизацию** торговых операций между мерчантами и трейдерами
- **Управление балансами** и финансовыми операциями
- **Систему споров** для разрешения конфликтов
- **Административную панель** для управления системой
- **API** для интеграций с внешними сервисами

## Основные компоненты

### Backend (Trade-Platform)
- **Технологии:** Go (Golang), PostgreSQL
- **API:** RESTful API с Swagger документацией
- **Функционал:** Управление заявками, балансами, спорами, пользователями

### Frontend (Trade-Frontend)
- **Технологии:** React + TypeScript
- **Интерфейсы:** Админ-панель, панели для мерчантов, трейдеров, тимлидов
- **Payment Window:** Окно оплаты для интеграции

## Роли в системе

В системе PandaPay существует 5 основных ролей:

1. **Мерчант** - создает заявки на обмен
2. **Трейдер** - выполняет заявки мерчантов
3. **Тимлид** - руководит командой трейдеров
4. **Админ** - управляет системой
5. **Суперадмин** - полный контроль над системой

Подробнее о каждой роли читайте в разделе [Роли и пользователи](/roles/merchant).
